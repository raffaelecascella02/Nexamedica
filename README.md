## 📌 Descrizione del Progetto
HealthTech Clinic è un'applicazione web full-stack basata su architettura **RESTful API** progettata per la gestione delle prenotazioni sanitarie e la consultazione dei referti medici.

L'architettura adotta un approccio **disaccoppiato (decoupled)**:
* **Backend:** Sviluppato in Python sfruttando l'architettura orientata agli oggetti e il framework **FastAPI**.
* **Frontend:** Realizzato in HTML5, CSS3 (Bootstrap 5) e JavaScript Vanilla per il consumo asincrono delle API tramite chiamate HTTP.
* **Documentazione:** Generazione automatica dello standard **OpenAPI 3.0 / Swagger UI**.

---

## 🛠️ Stack Tecnologico

* **Backend:** Python 3.11+, FastAPI, Pydantic, Uvicorn
* **Frontend:** HTML5, CSS3, JavaScript (Fetch API), Bootstrap 5
* **Testing API:** Thunder Client / Swagger UI
* **Version Control:** Git & GitHub
